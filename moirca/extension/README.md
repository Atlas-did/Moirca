# Moirca Chrome 浏览器扩展

> 比油猴脚本更强大的志愿填报辅助工具

## 功能

- 🔍 **智能表单侦测** — 多策略自动识别志愿填报表，支持7省
- ✍️ **一键填充** — 从 Moirca 推荐结果自动填入官方系统
- 📥 **结构化导出** — JSON下载 / 剪贴板复制
- 🗂️ **用户档案管理** — 选项页管理多套分数/省份配置
- 🏷️ **Shadow DOM 隔离** — UI完全隔离，不受页面CSS干扰
- 🔄 **跨标签页数据共享** — Moirca应用 ↔ 填报系统无缝传递

## 安装

1. 打开 Chrome → `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `moirca/extension/` 目录
5. 扩展图标出现在浏览器工具栏

## 使用

1. 在 Moirca 应用中获得推荐结果
2. 打开对应省份的官方志愿填报系统
3. 页面右侧自动出现「Moirca 填报助手」面板
4. 点击「从 Moirca 导入」→ 自动读取推荐数据
5. 点击「一键填充」→ 数据填入表单
6. 核对后自行提交

## 安全

- ❌ 不读取密码/验证码
- ❌ 不自动提交表单
- ❌ 不向外部服务器发送数据
- ✅ Shadow DOM 隔离，不与页面JS冲突
- ✅ 开源代码（AGPL-3.0）
